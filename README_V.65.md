# Office Task Report V.65

Attendance break-duration update.

## Break rules
- Lunch: maximum 25 minutes; seasonal example window 1:00 PM–4:00 PM.
- Zohar: maximum 30 minutes; seasonal example window 1:00 PM–2:00 PM.
- Asr: maximum 30 minutes; seasonal example window 3:45 PM–6:15 PM.
- Juma: maximum 70 minutes; seasonal example window 12:30 PM–3:00 PM.
- Magrib: maximum 30 minutes; seasonal example window 5:40 PM–7:30 PM.

The example time windows are informational because prayer times can vary by season/location. The fixed duty rule uses the maximum duration above.

## Duty calculation
Break duration up to the configured maximum remains counted as on-duty time. Only the excess above the maximum is excluded from duty minutes and appears in the separate Break Time Report as Extra Break Time.
